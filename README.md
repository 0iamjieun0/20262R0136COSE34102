# Python Stack Implementation

## Introduction

This repository contains a simple implementation of a stack
data structure using Python.

The purpose of this project is to practice basic Python
programming and GitHub version control.

## Features

The stack supports the following operations:

- push(): Add an element to the stack
- pop(): Remove the top element
- peek(): Return the top element
- size(): Return the number of elements
- is_empty(): Check whether the stack is empty

## Files

- stack.py: Implementation of the Stack class
- example.py: Example of stack operations

## How to Run

Run the following command:

python example.py

## Learning Objectives

- Understand the Last-In-First-Out (LIFO) principle
- Practice Python classes and methods
- Learn how to manage source code using GitHub
